# 🎭 소소 라이어게임

최대 10명이 모바일/PC 브라우저에서 방 코드로 접속해 즐기는 실시간 라이어게임입니다. 음성 대화는 Discord 등을 사용하고, 이 웹앱은 역할·질문·답변·투표·점수·타이머를 담당합니다.

## 주요 기능
- 5자리 방 코드 / 최대 10명 / 닉네임 / 30종 캐릭터
- 선택적 방 비밀번호
- 일반게임 / 질문게임
- 일반게임 단어 1,300개, 질문게임 질문 1,300개 이상
- 질문별 숫자 범위 적용 및 전원 제출 후 동시 공개
- 라이어 1~3명 설정
- 라운드 제한시간 및 투표 제한시간, 시간 만료 시 자동 진행
- 전원 투표 / 동률 처리 / 결과 공개
- 일반게임에서 검거된 라이어의 최종 단어 맞히기 기회
- 점수 및 연승 표시
- 방장 강퇴 / 방장 위임
- 새로고침·일시 네트워크 끊김 재접속 복구(최대 약 5분)
- 효과음 ON/OFF, 화면 애니메이션
- PWA 지원: 지원 브라우저에서 홈 화면/앱으로 설치 가능
- 반응형 모바일/PC UI

## 실행
Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

## 인터넷 공개 배포
Render, Railway, Fly.io 등 WebSocket을 지원하는 Node.js 호스팅에 배포하면 됩니다. 시작 명령은 `npm start`, 서버는 `process.env.PORT`를 자동 사용합니다.

> 현재 방 상태와 점수는 서버 메모리에 저장됩니다. 서버를 재시작하면 방이 사라집니다. 대규모/상용 운영은 Redis 같은 외부 저장소와 여러 서버 간 Socket.IO adapter를 붙이는 것을 권장합니다.

## 점수 규칙
- 라이어 검거 성공: 일반 플레이어 +1점
- 라이어에게 정확히 투표한 일반 플레이어: 추가 +1점
- 라이어 생존: 라이어 각각 +3점
- 검거된 라이어가 최종 단어를 맞힘: 해당 라이어 +2점

## 데이터
- `data/words.json`: 일반게임 단어
- `data/questions.json`: 질문게임 질문 및 min/max 범위
