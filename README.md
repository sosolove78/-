# 소소 파티게임 v9.5

모바일/PC 실시간 파티게임 웹앱입니다. Node.js + Express + Socket.IO 기반입니다.

## 포함 게임
- 라이어게임 (3~10명): 단어게임 / 질문게임, 단어게임의 일반모드·바보모드·랜덤, 카테고리 공개, 투표, 최종 단어 추측
- 마피아게임 (5~12명): 마피아 / 경찰 / 의사 / 시민, 역할 공개 연출, 밤·낮 UI, 사망자 마피아 공개
- 진실게임 (2~10명): 이지 / 노멀 / 하드, 플레이어별 성별 선택, 1,000개 이상 질문 풀
- 루미큐브 (2~4명): 106타일, 14개 시작 패, 첫 등록 30점, 드래그앤드롭, 턴 타이머, 정렬

## v9.5 변경사항
- 라이어게임 세부 게임 명칭을 `단어게임 / 질문게임`으로 정리
- 질문게임에서는 바보모드/랜덤모드 설정을 숨기고 일반 라이어 방식만 적용
- 라이어게임 대기실 설명을 단어 게임 / 질문 게임 중심으로 변경
- 마피아 역할 공개 화면의 문자 `두둥…` 제거, 효과음/연출만 유지
- 마피아 역할 팝업을 더 작고 가운데 정렬되도록 조정
- 마피아 대기실에서 현재 접속 인원 기준 직업 구성을 전원에게 공개
- 진실게임 성별 설정을 방장 설정과 분리하여 모든 참가자가 각자 선택
- 모든 실제 참가자가 성별을 선택해야 진실게임 시작 가능
- 루미큐브 PC 화면에서 참가자 목록을 왼쪽 세로형으로 배치
- 현재 차례 참가자를 노란 테두리로 표시하고 각 참가자의 남은 타일 수 공개
- 루미큐브 턴 종료 10초 전부터 매초 경고음, 10/3/2/1초 팝업 표시
- 그림퀴즈 관련 게임 로직과 메뉴 제거

## 관리자 테스트 모드
관리자 비밀번호는 `4890`입니다.

## 실행
```bash
npm install
npm start
```
브라우저에서 `http://localhost:3000` 접속.

## Render 배포
기존 GitHub 저장소에 파일을 덮어쓴 뒤 커밋하면 기존 Render Web Service가 자동 재배포됩니다.

## 주의
현재 방 상태는 서버 메모리에 저장되므로 Render 재배포/서버 재시작 시 진행 중 방은 초기화될 수 있습니다.
