# 소소 파티게임 v7

모바일/PC 실시간 파티게임 웹앱입니다. Node.js + Express + Socket.IO 기반입니다.

## 포함 게임
- 라이어게임 (3~10명): 일반 / 스파이 / 질문, 카테고리 공개, 투표 진행률, 최종 단어 추측
- 마피아게임 (5~12명): 마피아 / 경찰 / 의사 / 시민, 밤·낮 UI, 사망자 마피아 공개
- 진실게임 (2~10명): 이지 / 노멀 / 하드, 1,200개 이상 질문 풀
- 그림퀴즈 (2~10명): 실시간 그림판, 빠른 정답 순 점수, 모바일 포인터 지원
- 루미큐브 (2~4명): 106타일, 14개 시작 패, 첫 등록 30점, 드래그앤드롭, 턴 타이머, 정렬

## 실행
```bash
npm install
npm start
```
브라우저에서 `http://localhost:3000` 접속.

## Render 배포
기존 GitHub 저장소에 파일을 덮어쓴 뒤 커밋하면 기존 Render Web Service가 자동 재배포됩니다.

## 주의
현재 방 상태는 서버 메모리에 저장되므로 Render 재배포/서버 재시작 시 진행 중 방은 초기화될 수 있습니다.

## v8 변경사항
- PC 전용 대시보드형 시작 화면 + 모바일 반응형 시작 화면
- 시작 화면을 프로필 / 방 만들기 / 함께하기 3구역으로 재구성
- 라이어게임의 일반게임/질문게임 선택을 라이어게임 카드 바로 아래로 이동
- 그림퀴즈 메뉴 제거
- 자체 생성한 소소 파티게임 캐릭터 이미지 16종 적용
- 관리자 테스트 모드 및 AI 플레이어 추가/최소 인원/최대 인원/전부 제거 기능
- AI는 질문게임 숫자 제출, 라이어/마피아 투표, 마피아 밤 행동, 루미큐브 기본 턴 진행을 자동 처리

### 관리자 테스트 모드
기본 관리자 비밀번호는 `2580`입니다. 공개 배포에서는 Render의 Environment Variables에 `ADMIN_PASSWORD`를 추가해 원하는 비밀번호로 반드시 변경하는 것을 권장합니다.
