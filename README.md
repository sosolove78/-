# 소소 파티게임 v11

기존 파티게임에 **지니어스게임 방**과 확장형 **주식전쟁**을 추가한 버전입니다.

## 주식전쟁 핵심
- 4~10명 / 8라운드 / 1,000코인 시작
- 비밀정보의 출처와 신뢰도, 조각형 정보
- 1:1 밀담, 코인 송금, 인증정보 거래 계약
- 거래량과 익명 큰손 알림, 시장 전체 이벤트, 기업별 특성
- 매수·매도 수급이 주가에 일부 반영
- 3·6라운드 특급정보 경매
- 비밀 미션과 가넷 매치 옵션
- AFTER MARKET 결과/폭로 화면
- 딜러 텍스트 + 브라우저 한국어 음성, BGM/효과음/음량 조절
- 시작화면에서는 지니어스게임 방을 만들고, 방 안에서 주식전쟁을 선택

## 실행
```bash
npm install
npm start
```

> 참고: 현재 지니어스 프로필/가넷은 서버의 `data/genius-accounts.json`에 저장됩니다. Render 무료 인스턴스의 로컬 파일은 재배포/인스턴스 교체 시 영구 보존이 보장되지 않으므로, 장기 운영 시 PostgreSQL/Supabase 같은 외부 DB 연결을 권장합니다.
