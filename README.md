# 🎮 소소 게임룸 v17

모바일/PC 실시간 파티게임입니다. Node.js + Express + Socket.IO 기반입니다.

## v17 주요 변경

- 지니어스게임은 로그인한 실제 닉네임으로만 참여
- 지니어스 대기실/게임 중 플레이어 카드에 가넷·우승횟수 표시
- 주식전쟁 브리핑 준비 완료 시스템(전원 준비 또는 최대 3분)
- 주식전쟁 딜러 음성 속도 개선, BGM 기본 30%, 0~100% 음량 조절
- 주식전쟁 라운드 사이 정보 확인 시간과 결과 확인 시간 확대
- 각 플레이어가 딜러에게 게임 규칙/현재 공개시장 질문 가능
- 마피아게임 단계별 밤 진행, 마피아 합의 공격, 최후변론, 최종 처형투표
- 마피아 개인 추리노트, 사망자 관전자 화면, 공개 직업 주장, 종료 후 실제 직업 공개·어워드
- 사용자 제공 밤/낮/투표 배경음악 및 총소리 효과음 적용

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

> 지니어스 프로필은 현재 `data/genius-accounts.json`에 저장됩니다. Render 무료 인스턴스의 로컬 파일은 영구 저장소가 아니므로, 장기 운영 전 외부 DB 연결을 권장합니다.


## v13 주식전쟁 정보전 개편
- 플레이어 간 인증정보 거래 제거
- 딜러 공식 정보상점 추가: 시장/고급/특급 정보를 게임 내 코인으로 구매
- 딜러가 직접 판매한 정보는 항상 진실
- 플레이어 간에는 밀담과 코인 송금만 제공하며, 전달하는 정보의 진위는 시스템이 보증하지 않음
- 3·6라운드 특급정보 경매 유지
- 가넷은 영구 프로필 보상, 정보 구매는 주식전쟁 코인으로 분리

## v15 변경사항
- 방장이 직접 나가면 방 즉시 종료, 단순 연결 끊김은 재접속 가능 상태 유지
- 지니어스 대기실은 주식전쟁/비밀금고만 선택 가능, 선택 즉시 현재 선택 UI 동기화
- 지니어스 참가자 10색 토큰 및 가넷/우승 2줄 표시
- 브라우저 한국어 음성 중 자연스러운 음성을 우선 선택하고 딜러 발화 시 BGM 덕킹
- 주식전쟁 룰 설명 확장, 단계 시간 고정(정보 20초/경매 30초/시장 3분/결과 20초), MARKET OPEN 밀담 잠금, 내 순위만 표시, PC 레이아웃 확대
- 비밀금고 룰 설명/준비 단계 및 새 가로 배너/시놉시스 적용
- 마피아 진행자 음성 제거, 상단 진행 안내, 연인 핑크 테두리, 추리노트 접기, 마피아팀 채팅 테마 및 채팅 포커스 유지
